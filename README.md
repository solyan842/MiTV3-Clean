# MiTV3 Clean

Windows utility for auditing, cleaning and modernizing Xiaomi MiTV3 via ADB.

## Goals
- Connect to MiTV3 over ADB/LAN.
- Inventory installed packages from the real device.
- Classify packages before any destructive action.
- Disable first, uninstall for user 0 only when explicitly selected.
- Snapshot/restore package state.
- Install and set [Couchy Launcher](https://github.com/conreo/couchy-launcher) as HOME.
- Keep critical Android/TV services protected.

> Work in progress. The first release targets Windows x64 and .NET 8 WPF.
